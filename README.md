## 🔍 Qu'est-ce qu'ARCANA ?

ARCANA est un **escape game gratuit en ligne** jouable directement dans votre navigateur, sans inscription, sans téléchargement. Plongez dans une aventure cinématographique à travers 60 salles progressives réparties en 3 actes :

### Acte I — Le Manoir Maudit ★ Débutant
20 salles d'ambiance gothique médiévale. Énigmes d'observation et de logique pour découvrir les mécaniques du jeu.

### Acte II — La Cité Perdue ★★ Confirmé  
20 salles d'aventure archéologique — pirates, pharaons, labyrinthes, volcans. Calculs, Latin, probabilités.

### Acte III — Le Vaisseau de l'Oubli ★★★ Expert
20 salles de science-fiction sombre. Binaire, demi-vies, paradoxes logiques, chiffre de César, relativité.
